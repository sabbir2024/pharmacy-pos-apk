# Stock UI Components

| ফাইল | কাজ |
|------|-----|
| `AddProductModal.tsx` | নতুন ঔষধ অ্যাড / এডিট মডাল |
| `ProductCard.tsx` | একটি ঔষধের কার্ড (স্টক, দাম, এক্সপায়ারি ব্যাজ) |
| `ProductList.tsx` | FlatList দিয়ে সব ঔষধ দেখানো |
| `SearchBar.tsx` | ঔষধ সার্চ ইনপুট |
| `EmptyState.tsx` | খালি লিস্টের মেসেজ |
| `index.ts` | সব কম্পোনেন্ট একসাথে এক্সপোর্ট |

**ব্যবহার:**
```tsx
import { ProductList, AddProductModal } from "@/components/ui/stock";
